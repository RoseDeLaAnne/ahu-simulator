# Улучшенная анимация вентилятора - Документация

## Обзор

Реализованы улучшения анимации вентилятора в 3D сцене для более реалистичного и визуально впечатляющего отображения работы ПВУ.

## Реализованные улучшения

### 1. Плавное ускорение/замедление (Easing)

**Проблема:** Предыдущая реализация мгновенно меняла скорость вращения при изменении расхода воздуха.

**Решение:** Добавлена система плавного перехода между скоростями с ease-in-out кривой.

```javascript
// Инициализация состояния вентилятора
fanNode.userData.fanState = {
  currentRpm: 0,      // Текущая скорость
  targetRpm: 0,       // Целевая скорость
  blurIntensity: 0,   // Интенсивность blur эффекта
};

// Плавное ускорение с easing
var acceleration = 2.5; // RPM в секунду
var easing = 1 - Math.pow(1 - Math.min(Math.abs(rpmDiff) / targetRpm, 1), 2);
state.currentRpm += Math.sign(rpmDiff) * maxChange * (0.5 + easing * 0.5);
```

**Параметры:**
- `acceleration`: 2.5 RPM/сек (настраивается в `scene3d.json`)
- Ease-in-out кривая для естественного ускорения/замедления

### 2. Motion Blur эффект

**Проблема:** При высоких оборотах лопасти выглядели статично.

**Решение:** Динамическое изменение прозрачности лопастей при высоких скоростях.

```javascript
// Расчет blur эффекта
var blurThreshold = max_rpm * 0.6;  // 60% от максимальной скорости
if (currentRpm > blurThreshold) {
  var blurFactor = (currentRpm - blurThreshold) / (max_rpm - blurThreshold);
  blurIntensity = clamp(blurFactor, 0, 1);
}

// Применение к лопастям
blade.material.opacity = baseOpacity * (1 - blurIntensity * 0.4);
```

**Характеристики:**
- Активируется при скорости > 60% от максимальной
- Максимальное снижение прозрачности: 40%
- Плавный переход между состояниями

## Конфигурация

### scene3d.json

```json
{
  "animation_rules": {
    "fan_rotation": {
      "target_node": "pvu.fan.rotor",
      "axis": "X",
      "speed_signal": "flows.flow_fan_to_room.intensity",
      "max_rpm": 3.0,
      "acceleration": 2.5,
      "blur_threshold": 0.6
    }
  }
}
```

**Параметры:**
- `max_rpm`: Максимальная скорость вращения (обороты в секунду)
- `acceleration`: Скорость ускорения/замедления (RPM/сек)
- `blur_threshold`: Порог активации blur эффекта (0.0-1.0)

## Визуальные эффекты

### Низкая скорость (< 60% max)
- Четкие лопасти
- Плавное ускорение
- Полная непрозрачность

### Средняя скорость (60-80% max)
- Начало blur эффекта
- Легкое размытие лопастей
- Прозрачность 80-90%

### Высокая скорость (> 80% max)
- Выраженный blur эффект
- Сильное размытие лопастей
- Прозрачность 60-70%

## Производительность

- **CPU:** Минимальное влияние (~0.1ms на кадр)
- **GPU:** Нет дополнительной нагрузки (используется стандартная прозрачность)
- **Память:** +24 байта на узел вентилятора (состояние)
- **FPS:** Без влияния на целевые 30 FPS
