# План улучшения 3D-визуализации ПВУ

Этот каталог содержит документацию по улучшению системы 3D-визуализации для симулятора ПВУ.

## Структура документов

- **[MASTER_PLAN.md](MASTER_PLAN.md)** — Основной план с описанием всех фаз, задач и технических требований
- **[PROGRESS.md](PROGRESS.md)** — Отслеживание прогресса выполнения задач
- **[TECHNICAL_NOTES.md](TECHNICAL_NOTES.md)** — Технические заметки и решения (будет создан)

## Быстрый старт

### Для продолжения работы с чистой сессии:

1. Прочитайте [MASTER_PLAN.md](MASTER_PLAN.md) для понимания общей картины
2. Проверьте [PROGRESS.md](PROGRESS.md) для текущего статуса
3. Найдите первую незавершённую задачу со статусом ⏳ или 🚧
4. Начните работу с неё

### Текущая фаза

**Фаза 1: Быстрые победы**  
Фокус на улучшениях, которые дают быстрый визуальный эффект:
- Post-processing эффекты (Bloom, SSAO)
- Инструменты измерения
- Захват скриншотов

## Ключевые файлы проекта

### Frontend (3D-визуализация)
- `src/app/ui/assets/viewer3d.mjs` — Основной Three.js код
- `src/app/ui/render_modes/scene3d.py` — Python/Dash UI компоненты
- `data/visualization/scene3d.json` — Конфигурация сцены

### Backend (Симуляция)
- `src/app/simulation/equations.py` — Физические расчёты
- `src/app/simulation/state.py` — Состояние системы
- `src/app/services/simulation_service.py` — Сервис симуляции

### Модели
- `data/visualization/assets/pvu_installation.glb` — 3D-модель ПВУ
- `tooling/scene/build_blender_pvu.py` — Скрипт генерации модели

## Принципы работы

1. **Инкрементальность** — Каждая задача должна быть завершена и протестирована перед переходом к следующей
2. **Документирование** — Все изменения фиксируются в PROGRESS.md
3. **Тестирование** — Проверка производительности и визуального качества
4. **Обратная совместимость** — Новые функции не должны ломать существующие

## Метрики качества

- **FPS:** Не ниже 25 при всех эффектах
- **Время загрузки:** < 2 секунд для модели
- **Покрытие тестами:** > 80% для новых функций
- **Размер bundle:** Прирост < 200KB на фазу

## Контакты и вопросы

При возникновении вопросов или проблем:
1. Проверьте TECHNICAL_NOTES.md
2. Изучите существующий код в viewer3d.mjs
3. Обратитесь к документации Three.js
