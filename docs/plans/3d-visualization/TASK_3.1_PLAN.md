## Цель

Создать систему визуализации воздушных потоков в 3D-модели ПВУ с помощью векторного поля, показывающего направление и скорость движения воздуха через различные компоненты системы.

---

## Технические требования

### 1. Векторное поле
- Создать сетку точек в пространстве модели
- Рассчитать векторы направления потока для каждой точки
- Интерполяция между известными точками
- Адаптивная плотность сетки (больше точек в узких местах)

### 2. Режимы визуализации

#### 2.1 Стрелки (Arrows)
- THREE.ArrowHelper для каждого вектора
- Длина стрелки = скорость потока
- Цвет = скорость (градиент от синего к красному)
- Масштабирование для читаемости

#### 2.2 Линии тока (Streamlines)
- Интегрирование векторного поля
- Плавные кривые вдоль потока
- Цветовое кодирование скорости
- Анимация движения по линиям

#### 2.3 Частицы (Particles)
- THREE.Points для анимированных частиц
- Движение по векторному полю
- Fade in/out на границах
- Регенерация частиц на входах

### 3. Источники данных

#### 3.1 Статические данные
- Предрассчитанное векторное поле из CFD
- JSON файл с координатами и векторами
- Загрузка при инициализации

#### 3.2 Динамические данные (будущее)
- Интеграция с симуляцией в реальном времени
- Обновление векторов на основе параметров ПВУ
- WebSocket для потоковых данных

### 4. Производительность

#### Оптимизации
- Instanced rendering для стрелок
- Geometry pooling для частиц
- LOD для векторного поля (меньше векторов на дальних планах)
- Culling невидимых векторов
- Throttling обновлений (30 FPS для анимации)

#### Целевые метрики
- FPS: 25+ с 500 векторами
- FPS: 20+ с 1000 векторами
- Память: +30-50MB для векторного поля
- Время загрузки: < 1 секунда

### JavaScript Bridge (viewer3d_bridge.js)

```javascript
function syncFlowField(
    enabledCheckbox,
    mode,
    density,
    speed,
    colorScheme
) {
    const enabled = Array.isArray(enabledCheckbox) && 
                    enabledCheckbox.includes("enabled");
    
    if (!enabled) {
        window.pvu3d.setFlowFieldMode("off");
        return [[], mode, density, speed, colorScheme, "Потоки выключены"];
    }
    
    window.pvu3d.setFlowFieldMode(mode, {
        density: density / 100,
        animationSpeed: speed,
        colorScheme: colorScheme,
    });
    
    const stats = window.pvu3d.getFlowFieldStats();
    const statsText = `Режим: ${mode} | Векторов: ${stats.vectorCount} | FPS: ${stats.fps}`;
    
    return [
        ["enabled"],
        mode,
        density,
        speed,
        colorScheme,
        statsText
    ];
}
```
