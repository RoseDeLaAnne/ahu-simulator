## Ключевые возможности

### 1. Публичный API (7 функций)
- `setClippingMode(enabled, options)` - включение/выключение режима
- `addClippingPlane(planeData)` - добавление плоскости
- `updateClippingPlane(index, params)` - обновление параметров
- `removeClippingPlane(index)` - удаление плоскости
- `getClippingPlanes()` - получение данных всех плоскостей
- `clearClippingPlanes()` - очистка всех плоскостей
- `applyClippingPreset(preset)` - применение пресета

### 2. Пресеты сечений
- **X (YZ)** - вертикальное сечение по оси X
- **Y (XZ)** - горизонтальное сечение по оси Y
- **Z (XY)** - вертикальное сечение по оси Z
- **Diagonal** - диагональное сечение
- **Cross** - крестообразное сечение (X + Z)

### 3. Визуализация
- PlaneHelper размером 5 метров
- Жёлтый цвет плоскости (0xffff00)
- Белая рамка с прозрачностью для лучшей видимости
- Автоматическое скрытие при выключении

### 4. UI-контролы
- Checkbox включения/выключения режима
- Кнопки пресетов для быстрого создания
- Dropdown выбора плоскости для редактирования
- Параметры: Normal X/Y/Z, Constant, Inverted
- Кнопки: Добавить, Удалить, Очистить всё

## Примеры использования

### Горизонтальное сечение
```javascript
window.pvu3d.setClippingMode(true);
window.pvu3d.addClippingPlane({
  normal: [0, 1, 0],
  constant: -1.5,
  enabled: true,
  inverted: false
});
```

### Применение пресета
```javascript
window.pvu3d.applyClippingPreset("cross");
```

### Инверсия направления
```javascript
const index = window.pvu3d.addClippingPlane({
  normal: [1, 0, 0],
  constant: 0,
  enabled: true,
  inverted: false
});

// Инвертировать
window.pvu3d.updateClippingPlane(index, { inverted: true });
```
