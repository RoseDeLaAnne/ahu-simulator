## Что реализовано

Полнофункциональная система clipping planes для 3D-визуализации ПВУ, позволяющая "разрезать" модель плоскостями для просмотра внутренних узлов.

---

## Основные компоненты

### 1. Публичный API (viewer3d.mjs)
```javascript
window.pvu3d.setClippingMode(enabled, options)      // Включение/выключение
window.pvu3d.addClippingPlane(planeData)            // Добавить плоскость
window.pvu3d.updateClippingPlane(index, params)     // Обновить параметры
window.pvu3d.removeClippingPlane(index)             // Удалить плоскость
window.pvu3d.getClippingPlanes()                    // Получить данные
window.pvu3d.clearClippingPlanes()                  // Очистить всё
window.pvu3d.applyClippingPreset(preset)            // Применить пресет
```

### 2. Пресеты
- **x** - вертикальное сечение YZ
- **y** - горизонтальное сечение XZ
- **z** - вертикальное сечение XY
- **diagonal** - диагональное сечение
- **cross** - крестообразное (X + Z)

### 3. UI-контролы (scene3d.py)
- Checkbox включения режима
- 5 кнопок пресетов
- Dropdown выбора плоскости
- Параметры: Normal X/Y/Z, Constant, Inverted
- Кнопки: Добавить, Удалить, Очистить

### 4. Bridge интеграция (viewer3d_bridge.js)
- `syncClippingMode()` - обработка всех UI событий
- `_updateClippingOutputs()` - синхронизация UI
- Автоматическое обновление dropdown при изменениях

```
Плоскость: normal.x * x + normal.y * y + normal.z * z + constant = 0
- normal: единичный вектор нормали
- constant: расстояние от начала координат
- inverted: инверсия направления отсечения
```

## Примеры использования

### Быстрый старт
```javascript
// Применить пресет
window.pvu3d.applyClippingPreset("y");
```

### Ручное создание
```javascript
window.pvu3d.setClippingMode(true);
window.pvu3d.addClippingPlane({
  normal: [0, 1, 0],
  constant: -1.5,
  enabled: true,
  inverted: false
});
```

### Динамическое управление
```javascript
const planes = window.pvu3d.getClippingPlanes();
planes.planes.forEach((plane, index) => {
  window.pvu3d.updateClippingPlane(index, {
    constant: plane.constant + 0.1
  });
});
```
