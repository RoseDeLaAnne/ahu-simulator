## Реализованные функции

### Основные функции (viewer3d.mjs)

1. **`_createHeatmapGradientTexture()`**
   - Создаёт градиентную текстуру для окраски
   - Возвращает THREE.CanvasTexture

2. **`_interpolateTemperatureAtVertex(vertex, dataPoints)`**
   - Вычисляет температуру в точке методом IDW
   - Параметры: vertex (THREE.Vector3), dataPoints (Array)
   - Возвращает: температуру (°C)

3. **`_applyHeatmapToMesh(mesh, dataPoints, minTemp, maxTemp, previousDataPoints, animProgress)`**
   - Применяет тепловую карту к mesh
   - Поддержка анимации через previousDataPoints и animProgress
   - Обновляет UV-координаты вершин

4. **`_updateHeatmapAnimation()`**
   - Обновляет анимацию в каждом кадре
   - Вычисляет прогресс анимации
   - Перерисовывает mesh с новым прогрессом

5. **`setHeatmapMode(enabled, dataPoints, options)`**
   - Включает/выключает тепловую карту
   - Опции: minTemp, maxTemp, animate, animationDuration
   - Возвращает: boolean (успех/неудача)

6. **`updateHeatmapData(dataPoints, options)`** ⭐ НОВАЯ
   - Обновляет данные тепловой карты с анимацией
   - Используется для динамического обновления
   - Автоматически запускает анимацию

7. **`getHeatmapData()`**
   - Возвращает текущее состояние тепловой карты
   - Формат: {enabled, dataPoints}

### Bridge функции (viewer3d_bridge.js)

1. **`syncHeatmapMode(enabledCheckbox, minTemp, maxTemp, signals)`**
   - Синхронизирует состояние тепловой карты с UI
   - Автоматически выбирает между setHeatmapMode и updateHeatmapData
   - Извлекает данные из signals или использует тестовые

## Технические характеристики

### Производительность
- **Создание текстуры:** ~1ms (однократно)
- **Интерполяция:** O(n*m), где n=вершины, m=точки данных
- **Анимация:** ~2-5% CPU во время анимации
- **Память:** ~10KB на mesh (UV-координаты) + 8 байт на точку данных
- **FPS:** минимальное влияние после применения

### Точность
- **В точках измерения:** точное значение (distance < 0.01м)
- **Между точками:** плавная интерполяция IDW
- **Анимация:** линейная интерполяция (можно расширить до easing)

### Ограничения
- Применяется только к mesh с geometry
- Не работает на корпусе (фильтруется по роли)
- Требует минимум 1 точку данных
- UV-координаты перезаписываются
- Одна анимация за раз (новое обновление прерывает текущую)

## Использование

### Включение тепловой карты

```javascript
// Базовое использование
window.pvu3d.setHeatmapMode(true, dataPoints);

// С настройками
window.pvu3d.setHeatmapMode(true, dataPoints, {
  minTemp: -20,
  maxTemp: 50,
  animate: true,
  animationDuration: 1000
});
```

### Обновление данных с анимацией

```javascript
// Автоматическая анимация (1 секунда)
window.pvu3d.updateHeatmapData(newDataPoints);

// Быстрая анимация (500мс)
window.pvu3d.updateHeatmapData(newDataPoints, { animationDuration: 500 });

// Без анимации
window.pvu3d.updateHeatmapData(newDataPoints, { animate: false });
```
