## Визуальный эффект

Bloom эффект применяется к:

1. **Emissive материалам узлов** (маркеры, сенсоры)
   - Норма: зелёное свечение
   - Риск: жёлтое свечение
   - Авария: красное пульсирующее свечение

2. **Потокам воздуха** (flows)
   - Голубое свечение для воздухопотоков
   - Оранжевое свечение для нагретого воздуха

3. **Эффектам** (aura rings, plumes)
   - Атмосферные эффекты вокруг секций ПВУ
   - Индикаторы качества воздуха в помещении

## Параметры Bloom

### Strength (Интенсивность)
- **Диапазон:** 0.0 - 3.0
- **По умолчанию:** 1.2
- **Эффект:** Контролирует яркость свечения

### Radius (Радиус)
- **Диапазон:** 0.0 - 1.0
- **По умолчанию:** 0.4
- **Эффект:** Контролирует размер области размытия

### Threshold (Порог)
- **Диапазон:** 0.0 - 1.0
- **По умолчанию:** 0.85
- **Эффект:** Определяет минимальную яркость для применения эффекта
