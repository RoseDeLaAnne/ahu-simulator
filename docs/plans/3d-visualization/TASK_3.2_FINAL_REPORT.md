## 🏗️ Архитектурные решения

### 1. Dual Scene System
**Решение:** Две независимые сцены вместо одной с переключением состояния

**Преимущества:**
- Можно отображать разные состояния одновременно
- Независимое управление каждой сценой
- Простая реализация

**Недостатки:**
- Удвоенное потребление памяти для модели
- Решено: клонирование модели из кэша

### 2. Camera Synchronization в Render Loop
**Решение:** Синхронизация каждый кадр вместо event-based

**Преимущества:**
- Гарантирует синхронизацию
- Не зависит от событий OrbitControls
- Простая реализация

**Недостатки:**
- Небольшой overhead каждый кадр (~0.1ms)
- Приемлемо для 60 FPS

### 3. CSS Overlay для Visual Elements
**Решение:** CSS элементы вместо canvas рисования

**Преимущества:**
- Лучшая производительность
- Легко стилизовать
- Автоматическое масштабирование

**Недостатки:**
- Требует DOM манипуляции
- Минимальное влияние

### 4. Цветовое Кодирование на Основе Дельт
**Решение:** Вычисление нормализованной дельты для каждого signal

**Преимущества:**
- Объективная оценка изменений
- Разные алгоритмы для разных режимов
- Порог значимости 5%

**Недостатки:**
- Требует вычисления для каждого элемента
- Выполняется один раз, не в render loop
