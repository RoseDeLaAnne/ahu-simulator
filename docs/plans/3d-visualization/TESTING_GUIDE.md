# Руководство по тестированию Bloom эффекта

**Версия:** 1.0  
**Дата:** 2026-05-31

---

## Предварительные требования

1. Приложение запущено локально
2. Developer tools включены (переменная окружения или настройка)
3. Браузер поддерживает WebGL 2.0 (Chrome 90+, Firefox 88+, Safari 14+)

---

## Шаги тестирования

### 1. Запуск приложения

```bash
# Из корневой директории проекта
python -m app.main
```

Приложение должно запуститься на `http://localhost:8050`

### 2. Переход в 3D-режим

1. Откройте приложение в браузере
2. Нажмите кнопку "Цифровой двойник 3D" в верхней панели
3. Дождитесь загрузки 3D-модели

### 3. Открытие контролов Bloom

1. Прокрутите страницу вниз до секции developer tools
2. Найдите блок **"Post-processing: Bloom"**
3. Разверните секцию, если она свёрнута

### 4. Базовое тестирование

#### Тест 1: Включение/выключение эффекта

- [ ] Снимите галочку "Включить Bloom"
- [ ] **Ожидаемый результат:** Свечение узлов исчезает
- [ ] Поставьте галочку обратно
- [ ] **Ожидаемый результат:** Свечение узлов появляется

#### Тест 2: Изменение интенсивности (Strength)

- [ ] Установите slider "Интенсивность свечения" на минимум (0.0)
- [ ] **Ожидаемый результат:** Свечение едва заметно
- [ ] Установите slider на максимум (3.0)
- [ ] **Ожидаемый результат:** Яркое, интенсивное свечение
- [ ] Верните значение к 1.2

#### Тест 3: Изменение радиуса (Radius)

- [ ] Установите slider "Радиус размытия" на минимум (0.0)
- [ ] **Ожидаемый результат:** Резкое, сфокусированное свечение
- [ ] Установите slider на максимум (1.0)
- [ ] **Ожидаемый результат:** Мягкое, размытое свечение
- [ ] Верните значение к 0.4

#### Тест 4: Изменение порога (Threshold)

- [ ] Установите slider "Порог яркости" на минимум (0.0)
- [ ] **Ожидаемый результат:** Bloom применяется ко всем объектам
- [ ] Установите slider на максимум (1.0)
- [ ] **Ожидаемый результат:** Bloom применяется только к самым ярким объектам
- [ ] Верните значение к 0.85

#### Тест 5: Синхронизация input ↔ slider

- [ ] Введите значение 2.0 в поле "Интенсивность свечения"
- [ ] **Ожидаемый результат:** Slider автоматически перемещается на 2.0
- [ ] Переместите slider на 1.5
- [ ] **Ожидаемый результат:** Значение в поле обновляется на 1.5

### 5. Тестирование на разных сценариях

#### Сценарий 1: Нормальная работа

1. Выберите сценарий "Нормальная работа"
2. Проверьте зелёное свечение узлов
3. **Ожидаемый результат:** Мягкое зелёное свечение на активных узлах

#### Сценарий 2: Авария

1. Выберите сценарий с аварией (например, "Загрязнённый фильтр")
2. Проверьте красное пульсирующее свечение
3. **Ожидаемый результат:** Яркое красное свечение на узлах в аварийном состоянии

#### Сценарий 3: Зима

1. Выберите зимний сценарий
2. Проверьте голубое свечение потоков холодного воздуха
3. **Ожидаемый результат:** Холодные голубые тона с bloom эффектом

### 6. Тестирование производительности

#### Проверка FPS

1. Откройте DevTools браузера (F12)
2. Перейдите на вкладку Performance
3. Запустите запись
4. Включите/выключите Bloom несколько раз
5. Остановите запись
6. **Ожидаемый результат:** FPS не падает ниже 25-30

#### Проверка памяти

1. В DevTools перейдите на вкладку Memory
2. Сделайте snapshot до включения Bloom
3. Включите Bloom
4. Сделайте snapshot после включения
5. **Ожидаемый результат:** Прирост памяти < 50 MB

### 7. Кросс-браузерное тестирование

Повторите базовые тесты в:

- [ ] Chrome/Edge (последняя версия)
- [ ] Firefox (последняя версия)
- [ ] Safari (если доступен)

---

## Известные ограничения

1. **Мобильные устройства:** Bloom может быть отключен автоматически на слабых GPU
2. **Старые браузеры:** Требуется WebGL 2.0 поддержка
3. **Производительность:** На интегрированных GPU может наблюдаться снижение FPS

---

При обнаружении проблем укажите:

1. **Браузер и версия**
2. **Операционная система**
3. **GPU (если известно)**
4. **Шаги для воспроизведения**
5. **Ожидаемое поведение**
6. **Фактическое поведение**
7. **Скриншоты (если применимо)**

## Критерии успешного тестирования

- ✅ Все базовые тесты пройдены
- ✅ Эффект работает на всех сценариях
- ✅ FPS остаётся выше 25
- ✅ Нет визуальных артефактов
- ✅ Контролы работают корректно
- ✅ Синхронизация input ↔ slider работает
