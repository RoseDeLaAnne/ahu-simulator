## Выполненные задачи

### 1. Градиентная текстура

**Функция:** `_createHeatmapGradientTexture()`

Создаёт градиентную текстуру через Canvas API:
- **Размер:** 256x1 пикселей
- **Цветовая схема:**

  - 75% - Оранжевый (#f59e0b)
  - 100% - Красный горячий (#ef4444)

### 2. Интерполяция температуры (IDW)

**Метод:** Inverse Distance Weighting (обратные расстояния)

**Алгоритм:**
```
Для каждой вершины mesh:
  1. Вычислить расстояние до всех точек данных
  2. Если расстояние < 0.01м → использовать точное значение
  3. Иначе: T = Σ(Ti * wi) / Σ(wi)
     где wi = 1 / distance²
  4. Преобразовать T в UV-координату: u = (T - Tmin) / (Tmax - Tmin)
```

**Преимущества IDW:**
- Простая и быстрая реализация
- Плавные переходы между точками
- Точные значения в местах измерения
- Вес убывает квадратично с расстоянием

### 3. Применение к mesh

**Функция:** `_applyHeatmapToMesh(mesh, dataPoints, minTemp, maxTemp)`

**Процесс:**
1. Получить geometry и positions вершин
2. Создать/обновить UV-координаты
3. Для каждой вершины:
   - Преобразовать в world coordinates
   - Интерполировать температуру по IDW
   - Записать UV-координату для градиента
4. Сохранить оригинальный материал
5. Применить MeshBasicMaterial с градиентной текстурой

**Параметры материала:**
- `map`: градиентная текстура
- `transparent`: true
- `opacity`: 0.8
- `side`: THREE.DoubleSide

### 5. Управление режимом

**Функция:** `setHeatmapMode(enabled, dataPoints, options)`

**Параметры:**
- `enabled`: boolean - включить/выключить
- `dataPoints`: Array<{x, y, z, temperature}>
- `options`: {minTemp, maxTemp}

**Логика:**
- При включении: применяет тепловую карту ко всем секциям
- При выключении: восстанавливает оригинальные материалы
- Фильтрует mesh по роли (не применяется к корпусу)

### 6. UI-контролы

**Компонент:** `_scene3d_heatmap_tools()`

**Элементы:**
- Checkbox: "Включить тепловую карту"
- Input: Минимальная температура (по умолчанию -10°C)
- Input: Максимальная температура (по умолчанию +40°C)
- Подсказка с описанием функционала

### 7. Clientside Bridge

**Функция:** `syncHeatmapMode(enabledCheckbox, minTemp, maxTemp, signals)`

**Логика:**
1. Проверить состояние checkbox
2. Если выключен → очистить тепловую карту
3. Если включен:
   - Извлечь температурные данные из signals
   - Если данных нет → использовать тестовые точки
   - Вызвать `setHeatmapMode()` с данными

**Извлечение данных:**

## Использование

### Включение тепловой карты

1. Откройте developer tools секцию
2. Разверните "Тепловые карты"
3. Поставьте галочку "Включить тепловую карту"
4. Настройте диапазон температур (опционально)

### Настройка диапазона

- **Мин температура:** нижняя граница шкалы (синий цвет)
- **Макс температура:** верхняя граница шкалы (красный цвет)
- Значения между границами интерполируются по градиенту

### Источник данных

Данные берутся из текущих показаний симуляции:
- Температура наружного воздуха
- Температура после калорифера
- Температура приточного воздуха
- Температура в помещении

Если данных нет, используются тестовые значения.

## Технические характеристики

### Производительность

- **Создание текстуры:** ~1ms (однократно)
- **Интерполяция:** O(n*m), где n=вершины, m=точки данных
- **Память:** ~10KB на mesh (UV-координаты)
- **FPS:** минимальное влияние после применения

### Точность интерполяции

- **В точках измерения:** точное значение
- **Между точками:** плавная интерполяция IDW
- **Вдали от точек:** экстраполяция (может быть неточной)

### Ограничения

- Применяется только к mesh с geometry
- Не работает на корпусе (фильтруется по роли)
- Требует минимум 1 точку данных
- UV-координаты перезаписываются
