### 1. Режим измерения расстояний

### 2. Создание точек измерения

**Функция:** `_createMeasurementPoint(position)`

- Создаёт зелёную сферу (радиус 0.05м) в указанной позиции
- Добавляет glow эффект (полупрозрачная сфера радиусом 0.08м)
- Точка добавляется в `overlayRoot` для корректного отображения
- Сохраняется в массиве `measurementPoints`

### 3. Создание линий между точками

**Функция:** `_createMeasurementLine(point1, point2, distance)`

- Создаёт зелёную линию между двумя точками
- Вычисляет расстояние между точками
- Создаёт 3D-метку (sprite) с текстом расстояния в метрах
- Метка размещается в середине линии

### 4. 3D-метки с расстоянием

**Функция:** `_createMeasurementLabel(position, distance)`

- Создаёт canvas с текстом расстояния
- Фон: полупрозрачный чёрный
- Текст: белый, жирный, 24px Arial
- Формат: "X.XX м" (2 знака после запятой)
- Использует THREE.Sprite для отображения в 3D-пространстве
- `depthTest: false` для видимости через объекты

### 5. Обработка кликов

**Обновлена функция:** `_onClick(event)`

В режиме измерения:
1. Выполняется raycast по всей сцене
2. При попадании создаётся точка в месте пересечения
3. Если есть предыдущая точка, создаётся линия
4. Вычисляется и отображается расстояние

В обычном режиме:
- Работает стандартный выбор интерактивных объектов

### 6. Управление измерениями

**Функции:**

```javascript
setMeasurementMode(enabled: boolean): boolean
// Включает/выключает режим измерения
// При выключении очищает все измерения

getMeasurements(): Array<{point1, point2, distance}>
// Возвращает массив всех измерений
// Каждое измерение содержит координаты точек и расстояние

clearMeasurements(): boolean
// Удаляет все точки, линии и метки
// Освобождает ресурсы (geometry, material, texture)
```

### 8. Clientside Bridge

**Файл:** `src/app/ui/assets/viewer3d_bridge.js`

**Функция:** `syncMeasurementMode(modeCheckbox, clearClicks)`

Логика:
1. Определяет, какой элемент вызвал callback
2. Если нажата кнопка "Очистить" - вызывает `clearMeasurements()`
3. Если изменён checkbox - вызывает `setMeasurementMode()`
4. Получает текущие измерения через `getMeasurements()`
5. Формирует HTML-список для отображения
6. Возвращает обновлённое состояние checkbox и список

## Визуальные элементы

### Точки измерения
- **Цвет:** Зелёный (#00ff00)
- **Размер:** Радиус 0.05м (основная сфера)
- **Glow:** Радиус 0.08м, прозрачность 30%
- **Материал:** MeshBasicMaterial (не зависит от освещения)

### Линии
- **Цвет:** Зелёный (#00ff00)
- **Толщина:** 2px (linewidth)
- **Прозрачность:** 80%
- **Материал:** LineBasicMaterial

### Метки расстояния
- **Фон:** Чёрный полупрозрачный (rgba(0,0,0,0.7))
- **Текст:** Белый, жирный, 24px Arial
- **Формат:** "X.XX м"
- **Размер:** 0.5 × 0.125 единиц
- **Позиция:** Середина линии
- **depthTest:** false (видны через объекты)

## Использование

### Включение режима измерения

1. Откройте developer tools секцию
2. Разверните "Инструменты измерения"
3. Поставьте галочку "Режим измерения"

### Создание измерений

1. Кликните по модели в первой точке
2. Кликните по модели во второй точке
3. Появится линия с расстоянием
4. Продолжайте кликать для добавления точек
5. Каждая новая точка соединяется с предыдущей

### Просмотр измерений

- Список измерений отображается в UI-панели
- Формат: "Измерение N: X.XX м"
- Обновляется автоматически при добавлении точек

### Очистка измерений

- Нажмите кнопку "Очистить"
- Все точки, линии и метки будут удалены
- Режим измерения остаётся активным

## Технические характеристики

### Производительность
- **Память на точку:** ~5 KB (geometry + material + glow)
- **Память на линию:** ~3 KB (geometry + material)
- **Память на метку:** ~10 KB (canvas texture + sprite)
- **Итого на измерение:** ~23 KB

### Точность
- **Расстояние:** Вычисляется через `Vector3.distanceTo()`
- **Отображение:** 2 знака после запятой
- **Единицы:** Метры (зависит от масштаба модели)

### Ограничения
- Измерения не сохраняются между сессиями
- Нет измерения углов (запланировано)
- Нет экспорта измерений (запланировано)
- Линии не интерактивны (нельзя редактировать)
