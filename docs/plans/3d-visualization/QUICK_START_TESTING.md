## Быстрая проверка функционала

### 1. Bloom эффект (30 секунд)

1. Откройте приложение в браузере
2. Переключитесь в режим "Цифровой двойник 3D"
3. Прокрутите вниз до секции "Post-processing: Bloom"
4. **Проверка:** Снимите галочку "Включить Bloom" → свечение исчезает
5. **Проверка:** Поставьте галочку обратно → свечение появляется
6. **Проверка:** Измените slider "Интенсивность" → яркость меняется

**Ожидаемый результат:** ✅ Bloom эффект работает, контролы реагируют

---

### 2. Инструменты измерения (1 минута)

1. Прокрутите до секции "Инструменты измерения"
2. Поставьте галочку "Режим измерения"
3. **Проверка:** Кликните по модели → появляется зелёная точка
4. **Проверка:** Кликните в другом месте → появляется линия с расстоянием
5. **Проверка:** Нажмите "Очистить" → всё удаляется

**Ожидаемый результат:** ✅ Измерения работают, расстояния отображаются

---

### 3. Захват скриншотов (30 секунд)

1. Прокрутите до секции "Захват скриншотов"
2. Выберите масштаб "2x (Full HD)"
3. Выберите формат "PNG"
4. **Проверка:** Нажмите "📷 Сделать скриншот"
5. **Проверка:** Файл автоматически скачивается
6. **Проверка:** Имя файла содержит дату и время

**Ожидаемый результат:** ✅ Скриншот сохранён, имя корректное

## Быстрая диагностика проблем

### Bloom не работает

**Симптом:** Галочка не влияет на свечение

**Решение:**
1. Откройте DevTools (F12) → Console
2. Проверьте ошибки JavaScript
3. Убедитесь, что `window.pvu3d.setBloomEnabled` существует
4. Проверьте, что WebGL 2.0 поддерживается

### Измерения не создаются

**Симптом:** Клики не создают точки

**Решение:**
1. Убедитесь, что галочка "Режим измерения" включена
2. Проверьте Console на ошибки
3. Убедитесь, что `window.pvu3d.setMeasurementMode` существует
4. Попробуйте кликнуть по самой модели, а не по фону

### Скриншот не скачивается

**Симптом:** Кнопка не реагирует или нет скачивания

**Решение:**
1. Проверьте Console на ошибки
2. Убедитесь, что `window.pvu3d.captureScreenshot` существует
3. Проверьте настройки браузера (разрешены ли скачивания)
4. Попробуйте другой масштаб (1x вместо 4x)
