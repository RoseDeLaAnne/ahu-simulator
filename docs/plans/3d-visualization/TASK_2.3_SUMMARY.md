## Что реализовано

### Система LOD (Level of Detail)
- Автоматическое упрощение геометрии объектов на расстоянии
- Три уровня детализации: High (100%), Medium (60%), Low (30%)
- Фильтрация: объекты < 100 вершин не упрощаются

### API (3 функции)
```javascript
window.pvu3d.setLODMode(enabled, options)
window.pvu3d.getLODStats()
window.pvu3d.applyLODPreset(preset)
```

### Пресеты (3 штуки)
- **Performance** — 0/10/20м, FPS +40-50%
- **Balanced** — 0/15/30м, FPS +30-40% (рекомендуется)
- **Quality** — 0/25/50м, FPS +15-25%

### UI-контролы
- Checkbox включения/выключения
- Кнопки пресетов
- Поля ввода дистанций
- Статистика в реальном времени
