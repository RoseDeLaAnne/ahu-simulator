### 1. Функция синхронизации камер

**Файл:** `src/app/ui/assets/viewer3d.mjs:2963-2983`

```javascript
function _syncCameras() {
  if (!comparisonCameraAfter || !camera || !controls) return;

  // Copy camera position and rotation
  comparisonCameraAfter.position.copy(camera.position);
  comparisonCameraAfter.rotation.copy(camera.rotation);
  comparisonCameraAfter.quaternion.copy(camera.quaternion);

  // Copy camera properties
  comparisonCameraAfter.zoom = camera.zoom;
  comparisonCameraAfter.fov = camera.fov;
  comparisonCameraAfter.near = camera.near;
  comparisonCameraAfter.far = camera.far;
}
```

**Что копируется:**
- Position (x, y, z)
- Rotation (euler angles)
- Quaternion (для точной ориентации)
- Zoom level
- Field of view
- Near/far clipping planes

**Что НЕ копируется:**
- Aspect ratio (устанавливается отдельно для каждого viewport)

### 2. Интеграция в render loop

## 🏗️ Архитектурные решения

### 1. Синхронизация в render loop
**Почему:** Простое и надёжное решение без event listeners

**Преимущества:**
- Гарантирует синхронизацию каждый кадр
- Не зависит от событий OrbitControls
- Работает с любыми изменениями камеры
- Минимальный код

**Недостатки:**
- Небольшой overhead каждый кадр (~0.1ms)
- Но это приемлемо для 60 FPS

### 2. Копирование всех свойств камеры
**Почему:** Полная синхронизация состояния

**Что копируется:**
- Трансформация: position, rotation, quaternion
- Проекция: zoom, fov
- Clipping: near, far

**Что не копируется:**
- Aspect ratio (зависит от размера viewport)

### 3. Условная синхронизация
**Почему:** Поддержка независимого режима

**Условия:**
- `comparisonMode === true` - режим сравнения активен
- `comparisonSyncCameras === true` - синхронизация включена

**Результат:**
- Можно переключаться между режимами
- Не влияет на производительность когда выключена
