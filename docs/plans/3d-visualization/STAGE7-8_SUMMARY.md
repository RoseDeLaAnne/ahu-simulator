### Технические детали:
```javascript
function _syncCameras() {
  if (!comparisonCameraAfter || !camera || !controls) return;
  comparisonCameraAfter.position.copy(camera.position);
  comparisonCameraAfter.rotation.copy(camera.rotation);
  comparisonCameraAfter.quaternion.copy(camera.quaternion);
  comparisonCameraAfter.zoom = camera.zoom;
  comparisonCameraAfter.fov = camera.fov;
  comparisonCameraAfter.near = camera.near;
  comparisonCameraAfter.far = camera.far;
}
```

## 🏗️ Архитектурные решения

### 1. Синхронизация в render loop
**Преимущества:**
- Гарантирует синхронизацию каждый кадр
- Не зависит от событий OrbitControls
- Работает с любыми изменениями камеры
- Минимальный код

**Overhead:** ~0.1ms per frame (незаметно при 60 FPS)

### 2. Цветовое кодирование на основе дельт
**Преимущества:**
- Объективная оценка изменений
- Порог 5% для значимости
- Разные алгоритмы для разных режимов
- Учёт специфики каждой метрики

**Пример:**
- Status: green → amber = worsened (красный)
- Temperature: 20°C → 22°C = improved (зелёный, если охлаждение)
- Power: 100kW → 80kW = improved (зелёный, меньше = лучше)

### 3. Применение только к "after" сцене
**Преимущества:**
- "Before" показывает исходное состояние
- "After" показывает новое + различия
- Легко сравнивать визуально
- Не перегружает восприятие

### 4. Оптимизация обновления режима
**Результат:**
- Полная перезагрузка: ~500ms
- Обновление diffMode: ~50ms
- **Ускорение: 10x**
